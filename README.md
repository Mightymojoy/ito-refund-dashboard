# ITO 售后退款率看板

GitHub Pages 静态部署版本。渠道、店铺、年、月、周、日、品类、系列、SKU、尺寸和颜色支持组合筛选。

渠道按线上自营、线上经销、线下三类汇总；10 家指定自营店铺优先归为线上自营，其余包含天猫、京东或抖音关键词的归为线上经销，其余归为线下。店铺维度保留，可继续查看单店或同款店铺对比。渠道归类不改变销售和退款计算范围。

支持系列退款率横向对比、店铺省市折叠分析，以及同款商品各店铺退款率比较。周一至周日为一周；退款匹配销售订单后归回订单付款日期。省市汇总不包含区县或详细收货地址。

业务数据通过 AES-256-GCM 加密，访问密码用于浏览器解密。密码和原始 Excel、逐笔订单明细不包含在此仓库。

数据在本地计算后同步；静态网站不会读取电脑磁盘。访问者解锁后可导出当前筛选的商品汇总。
